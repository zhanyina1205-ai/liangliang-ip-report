08 / OPERATING PRINCIPLES

Lessons from the Case

  1. 定位要转成可执行的选题

    把人群、场景、需求和效果写清楚，再决定内容形式，让每条内容都有明确的观看理由。

  2. 矩阵要有分工，也要可识别

    美妆提供方法，穿搭展示审美，日常补充人物。评估各号价值时分别看数据，不简单相加粉丝。

  3. 复盘要落到下一次内容决策

    拆解峰值，也观察日常中位数和净增粉。把数据问题转成下一轮要验证的选题、表达或承接调整。

3. 人设与内容特点

可人设“会化妆、会搭配、愿意分享方法的变美同伴”。

  • 实用场景明确：公开作品有眼镜党淡妆、新手第一套大牌彩妆、泰式水光妆等，常通过人群或需求限定选题。
  • 兼顾教程与个人审美：公开列表既有20分钟无剪辑妆教，也有旅行拆箱、行李箱收纳、运镜与短视频；说明主号本身也包含生活和好物，账号边界并非完全隔离。
  • 整体IP判断：围绕“变美与审美生活”拓展内容，而非只依赖单一化妆技巧。跨号受众重合、导流率和商业贡献暂无数据。

6. 可借鉴的三个重点

  1. 用统一审美连接账号：先定义“这个人为什么值得关注”，再安排美妆、穿搭和生活内容，各号主题可以不同，人物表达要可识别。
  2. 把选题写成具体需求：围绕人群、场景或想达到的效果组织内容；对标时记录标题承诺与最终展示是否一致。
  3. 同时观察爆款与日常表现：重点学习她选题和人物表达的规律；不要用峰值播放量预测自己或一次商单的效果。
